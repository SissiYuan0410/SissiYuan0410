Project 1: Drop

Interactive Experience

About This Project

This p5.js program generates an interactive, time-responsive visual effect that simulates falling "grains" (colored squares) that accumulate at the bottom of the canvas, creating a stacked, growing structure. The color of the grains is dynamically tied to the current hour of the day, adding a real-time temporal dimension to the visualization.
