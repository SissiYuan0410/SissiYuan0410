Project 2：Face

This p5.js program creates a static yet interactive visual of a stylized face that randomizes its properties when the user presses the spacebar. The face features dynamic variations in position, color, and eye shape, blending basic primitive shapes with custom vector graphics (hearts) for a playful, customizable effect.
